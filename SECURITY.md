# Security Policy

## Supported Versions

Currently, this repository is focused on being a sandbox for beginner open source contributions (specifically Hacktoberfest). Since it is primarily static HTML and markdown files used for educational purposes, there are no "versions" maintained in the traditional software release sense.

All active maintenance and updates occur on the `master` branch.

## Reporting a Vulnerability

If you discover a security vulnerability within this repository (e.g., malicious scripts injected in the HTML files, compromised translation links, etc.), please do **NOT** open a public issue.

Instead, please report it privately via email:

**Email:** alfikridev@gmail.com

### What to include in your report:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- (Optional) Suggested mitigation or fix.

### Our Response Time
We will strive to acknowledge your report within 48 hours and will provide an estimated timeline for remediation. We appreciate your efforts in keeping this educational project safe for everyone!
